# Features for v1.1

## Proposed features
## Server Offload and streaming
1. Remote Blazor app which serves as a 'backend server' for the robot (2way apis) AND a client interface (henceforth called desktop ui).
2. Ability for Streaming video from robot to be displayed in Blazor app (see what the robot is seeing)
3. Camera tool use snapshots captured or tagged to be shown in the desktop UI
4. Robot can call tools on remote server (for instance, robot can call KinectShot and capture an image from the Kinect v2 camera on the server [or any camera the server exposes])
5. Robot can call tools like "scheduler" on server which allows robot to schedule a meeting for instance

## Sub-agents and other models
1. A means of spawning sub-agents and tracking their execution (with timeouts) and collecting the outcome of those sub-agents. Subagents might be on the server or local to the robot.
2. A means of offloading complex thinking to a smarter model. (the realtime model isn't particularly intelligent)

## Personality
1. A first pass at a more thoughtful personality system as laid out in Docs/openclaw-personality-findings.md

## Knowledge and Persistence
1. A means of storing knowledge and hydrating that knowledge on related requests via queries to the server which holds: vectordb, full-text-db , and perhaps a graph db.

## Always On
1. A first pass at how we might integrate some of the findings from 'always on' as laid out in Docs/openclaw-always-on-findings.md
